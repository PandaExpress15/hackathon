# CareerProof AI

CareerProof AI helps students explore financially sustainable, AI-resilient careers with official data, transparent calculations, evidence passports, and safe refusal.

This file is provided for a Docker-based Hugging Face Space. Copy it to the repository root as `README.md` when creating a separate Space repository. The root `Dockerfile` already serves the FastAPI application on port 7860.
