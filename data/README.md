# Bundled Data

`data/raw/` contains official source snapshots from BLS and O*NET. `data/processed/` contains normalized analytical tables built by `scripts/build_official_data.py`. `data/metadata/data_catalog.json` records provenance and SHA-256 checksums.

No synthetic labor-market records are bundled.

See `docs/DATA_SOURCES.md` for authoritative URLs, releases, terms, transport notes, fields, and limitations.
