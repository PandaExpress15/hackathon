# CareerProof AI Dataset

## Disclosure

This dataset is synthetic and was generated for demonstration and evaluation. It does not represent current real-world hiring conditions.

## Files

- `raw/job_postings.csv` - canonical demonstration input
- `raw/job_postings.xlsx` - formatted workbook with a data dictionary and disclosure sheet
- `processed/cleaned_job_postings.csv` - generated by the application after transparent cleaning

## Generation

```bash
python scripts/generate_dataset.py
```

The generator uses the fixed seed `20260730`. Re-running it produces the same base records and patterns.

## Design goals

The synthetic data includes realistic variation across:

- 10 job-role categories
- 18 fictional companies
- 16 United States cities
- 5 experience levels
- Remote, hybrid, and on-site work modes
- Salary ranges
- Required and preferred skills
- Fictional recruiter contacts using reserved example domains and 555 phone numbers

The data intentionally includes controlled quality issues so the application can demonstrate duplicate detection, invalid salary handling, date validation, missingness, unknown-category handling, and a visible cleaning ledger.

## Privacy

All names, companies, emails, phone numbers, source IDs, and postings are fictional. Recruiter fields are still treated as sensitive and masked by the application to demonstrate privacy-by-design.
