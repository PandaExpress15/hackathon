## Participant Guide alignment

The participant guide requires a real user problem, supported data, meaningful AI assistance, a visible trust or control feature, and a working demonstration. CareerProof AI provides all five through its career decision workflow, official labor-market and education datasets, controlled natural-language interpretation, evidence passports and safe refusal, and a working browser application.

The Track 2 workflow requires a dataset, user questions, verified answers calculated with code, and visible evidence. CareerProof includes eight documented official source families, supported question routing, deterministic calculations, and source/calculation views for important answers.
