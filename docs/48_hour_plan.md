# 48-Hour Build Plan

## Phase 1 - Define

- Select Track 2 and target students and early-career job seekers.
- Define the question-to-evidence workflow.
- Choose a deterministic synthetic job-posting dataset.
- Commit the project scaffold and disclosure documents.

## Phase 2 - Core workflow

- Generate the dataset.
- Build schema mapping, cleaning, quality reporting, and fingerprinting.
- Build three deterministic question routes.
- Add the first working Gradio interface.

## Phase 3 - Trust layer

- Add query-plan allowlists.
- Add PII masking.
- Add source rows, calculation details, and confidence labels.
- Add unsupported-question refusal.

## Phase 4 - Advanced features

- Add Evidence Passport, downloadable proof bundle, and active-dataset replay verifier.
- Add Refusal Coach.
- Add Career Signal Lab.
- Add Scenario Compare.
- Add data-quality and audit tabs.

## Phase 5 - Test and improve

- Add unit, integration, privacy, export, refusal, and adversarial tests.
- Run all judge-ready questions.
- Fix failures and verify deterministic outputs.
- Review UI hierarchy, mobile behavior, chart labels, and error messages.

## Phase 6 - Submission readiness

- Complete README, architecture, presentation, demo script, disclosures, and judging alignment.
- Run `scripts/smoke_test_app.py` and `scripts/verify_submission.py`.
- Build, extract, retest, and inspect the final ZIP.
- Push the actual commit history to a public GitHub repository.
- Record and upload the video.
- Complete the official form.
