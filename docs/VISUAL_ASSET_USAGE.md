# Visual Asset Usage

## Build variant

**Full visual showcase submission candidate**

Uses approved screenshot-grounded artwork in the homepage journey, Career Universe overview, and Skills Bridge visual surface while preserving live data, controls, and evidence workflows.

## Approved visual references

The approved design screenshots are preserved in `docs/design-references/` for traceability. They are not used as whole-page screenshots or fake interactive interfaces. Static artwork is used only where the content is decorative and non-data-driven.

### Rules followed

- Navigation, forms, buttons, calculations, charts, evidence, and results remain real HTML and JavaScript.
- Official values remain loaded from the bundled data and API routes.
- Screenshot crops are not presented as official data.
- The homepage journey art has accessible text through the surrounding real content.
- Career Universe planets do not spin when selected. The transition uses focus and zoom only.
- Career moons remain fixed after they appear.
- Reduced-motion behavior remains supported.

## Image provenance

The design references were generated and iterated with OpenAI image generation during the project design process. The application code, data calculations, evidence system, and interactive behavior are implemented in the repository.
