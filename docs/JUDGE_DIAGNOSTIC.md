## Most likely judge objections

### “This is only filtering.”

Response: The interface visibly separates controlled interpretation, TF-IDF retrieval, hard feasibility, deterministic ranking, resilience modeling, counterfactual sensitivity, and explanation.

### “The resilience score is arbitrary.”

Response: The model card exposes dimensions, weights, lexicons, normalization, matched evidence, formula, version, and limitations.

### “The interface overclaims AI-proof careers.”

Response: The hero and result boundaries state that no career is permanently AI-proof. Resilience is relative and inspectable.

### “More data means more hidden mismatch.”

Response: A persistent warning names every source vintage and says the values are not one synchronized snapshot.

### “A recommendation could ignore a hard constraint.”

Response: Education, salary, and location hard gates are evaluated before ranking. Blocked careers are labeled and cannot silently win.

### “One broken demo click will lower confidence.”

Response: 33 browser acceptance checks cover all main interactions, and Judge Mode has a one-click reset.
