# CareerProof AI visual audit before fidelity pass

## Home
- The headline was too large and wrapped like a pasted quotation.
- The staircase read as disconnected floating blocks.
- Five evidence metrics competed in one strip.
- The user snapshot was too tall and the lower page repeated information.

## Career Universe
- Planet surfaces looked like glossy circles rather than physical worlds.
- The stage needed darker cinematic contrast and subtler supporting chrome.
- Moon motion had to be explicitly locked to fixed coordinates.

## Degree Explorer
- The empty state used an oversized black graduation-cap placeholder.
- Most of the main panel was empty and offered no useful starting points.
- The page lacked the academic pathway identity planned for the feature.

## Shared issues
- Several pages used the same violet wash.
- Some page headings were oversized relative to the tools below.
- Card density and blank space were inconsistent.
- Page-specific accent colors were not distinct enough.
